# Changelog

## Unreleased

- Per-pane rows in the coordinator (`tern_sidepulse/coordinator.py`, `tern_sidepulse/reducer.py`): observations are keyed by `(host, pane)` (`local`, or a remote host's `address`, `name`, or `id:<n>`) and deduplicated across windows by mode priority (`blocked_error`, `waiting_for_input`, `working`, `completed`, `idle_ready`) and newest label, while the SidePulse hook-event transport continues to emit one combined session (`OMP in Tern`).
- In-memory session labels (`window.luau`, `tern_sidepulse/reducer.py`, `tests/test_privacy.py`, `tests/test_rows.py`): when a window has at least one OMP pane, `window.luau` reads `cx.session:panes()` and `cx.session:tabs()` at most once per 5 s pass and labels each OMP pane from its user-given tab name (`TabInfo.name`) or its own `PaneInfo.title` (cut to 256 UTF-8 bytes in the window and sanitized in the coordinator to at most 96 characters without control, surrogate, or private-use characters). Labels and host keys stay in coordinator memory only and never appear in `coordinator.log`, `doctor.json`, `bridge.py status`, coordinator acknowledgements, or the SidePulse payload (`status` and `doctor` report row counts and allow-listed diagnostic counters only).
- Snapshot budget and request limits (`window.luau`, `tern_sidepulse/limits.py`): the window keeps each encoded snapshot within 192 KiB by dropping labels and retrying once (`labels_dropped`), host keys are capped at 128 bytes in the window and 128 characters in the coordinator, and the coordinator request cap is raised from 256 KiB to 1 MiB.
- Headless Luau window harness (`tests/luau/`, `tests/test_luau_harness.py`, `.github/workflows/ci.yml`): runs the real `window.luau` under the `luau` 0.745 CLI across the backoff/interpreter/latch/role test drive (`drive_backoff.luau`, scenarios A–G), the label and host-key drive (`drive_labels.luau`, scenarios L1–L12), and the snapshot-budget drive (`drive_budget.luau`, scenarios B1–B3), bringing the suite to 155 unit and integration tests.

## 0.1.0 — 2026-11-05

First release.

- Window plugin (`window.luau`) for [Tern](https://stencil.so/tern): observes the [OMP](https://github.com/can1357/oh-my-pi) sessions visible in open Tern windows across local and attached remote hosts, classifies panes by their `omp.session` surface role, and reports aggregate status (`working`, `waiting_for_input`, `completed`, `blocked_error`, `idle_ready`) on [SidePulse](https://github.com/inteliwear/sidepulse) as one synthetic session (`tern-sidepulse:<install_id>`).
- Standard-library Python 3.10+ helper and on-demand per-user coordinator (`bridge.py`, `tern_sidepulse`): singleton lock, observer registration and 15 s leases, fixed-deadline outcome notices (15 s completion, 30 s failure), sleep-aware clock checks, bounded retry to both SidePulse receivers (`events.sock` for the menu-bar app and `relay-events.sock` for the headless service), and automatic `idle_ready` clear and exit after the last window closes.
- Tern command palette actions (`tern-sidepulse: doctor`, `tern-sidepulse: resync`, `tern-sidepulse: disable`, `tern-sidepulse: enable`) and matching `bridge.py` CLI commands (`status`, `doctor`, `resync`, `disable`, `enable`).
- Verified against Tern 0.9.12 (`e498b49`), OMP 18.16.0, and SidePulse `0.2.4.dev6+gffb1d3c2f` (revision `ffb1d3c2`) with 111 unit and integration tests; see [docs/compatibility.md](docs/compatibility.md).
- Hardening: isolated `python3 -I -S` helper launches with bytecode cached under the plugin data directory (`pycache/`), strict UTF-8 JSON validation and 256 KiB request / 32-connection caps on the coordinator socket, mode `0600` runtime and state files in a `0700` directory, and automatic rejection of pre-3.10 interpreters with exponential retry backoff up to 30 s (see commits `bf38d95` and `8446d6a`).
- Presentation: the Pane mark, banner and social preview (`assets/`), a synthetic demo animation (`docs/media/`, rendered by `scripts/render_assets.py`), the public site (`site/`, deployed by `.github/workflows/pages.yml`), the brand spec (`docs/BRAND.md`), and `tests/test_site.py`, which keeps the README, `plugin.toml`, the palette commands, and the site coherent.
